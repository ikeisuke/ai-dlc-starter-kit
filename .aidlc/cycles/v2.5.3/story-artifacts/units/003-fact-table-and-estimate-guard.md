# Unit: 事実テーブル先抽出ステップ + 推定値検出ガード（#634 絞込）

## 概要

振り返り作業時の推測値混入バグを構造的に予防する。`skills/aidlc/steps/operations/04-completion.md` §1 に「事実テーブル先抽出ステップ」を追加し、`skills/aidlc/steps/common/review-flow.md` に「推定値検出ガード」を追加する。3層検証 skill 化（jsonl 解析等）は OUT_OF_SCOPE（#652）として切り出し済。

## 含まれるユーザーストーリー

- ストーリー 3: 振り返り作業での推測値混入を予防する（#634 絞込）

## 責務

- `skills/aidlc/steps/operations/04-completion.md` §1.x（§1.1 KPT テンプレと §1.2 主因切り分けの間）に「事実テーブル先抽出ステップ」を追加
  - 読み込み対象 source（最低 3 つ）: `decisions.md` / `construction/units/*-review-summary.md` / `history/*.md`
  - 事実テーブルの形式（DR 件数 / review round 数 / 指摘件数 / defer 件数 / 時系列イベントの構造化）を手順記述レベルで定義
- `skills/aidlc/steps/common/review-flow.md` に「推定値検出ガード」を追加
  - 検出マーカー: `約`, `およそ`, `approximately`, `approx.`, `推定`, `〜くらい`, `〜程度` 等
  - 数値隣接判定: 直前または直後 5 文字以内に算用数字または日本語数字
  - 根拠リンク併記時の例外: 同一段落内に PR/Commit/Issue リンクまたはファイルパス参照あり
  - 許容例 / 非許容例を 2 件以上併記
- AI レビューワー応答の判定出力期待（**ケース別 / 主判定**）:
  - **flag されるべきケース**（推定値混入かつ根拠リンク併記なし）: 「指摘 #N - 推定値混入: `<該当箇所>`」形式が **必ず 1 件以上** 含まれる
  - **flag されないべきケース**（根拠リンク併記ありの許容入力）: 「指摘 #N - 推定値混入: ...」形式の指摘が **0 件**（誤検知が出ない）
  - 両ケースが Construction Phase の合否判定で同時に評価される
