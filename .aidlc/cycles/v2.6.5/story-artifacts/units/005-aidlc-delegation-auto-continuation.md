# Unit: /aidlc 委譲フロー Skill ツール経由自動継続実行規約化

## 概要

`skills/aidlc/SKILL.md` の「独立フロー委譲」セクションを更新し、`/aidlc r` / `/aidlc setup` / `/aidlc migrate` / `/aidlc feedback` を入力した際に、AI エージェントが委譲案内テキストを介さず Skill ツール経由で対象スキルを直接 invoke する規約を明文化する。`/aidlc r` 等の UX 摩擦（一旦止まる → 案内テキスト読む → 再入力）を解消する。

## 含まれるユーザーストーリー

- ストーリー 5: /aidlc 委譲フローを Skill ツール経由で自動継続実行する

## 責務

- `skills/aidlc/SKILL.md` の「独立フロー委譲」セクション（アンカー: `## 引数処理` 配下の「独立フロー委譲」見出し節）の更新
- 新規約の構成要素: (a) 委譲先スキル名と AskUserQuestion を介さない継続 invoke 手順、(b) `additional_context` の透過渡しルール、(c) 委譲案内テキストを「実行済み報告」形式に変更
- 委譲廃止案（#717 提案 2）を採用しない旨を SKILL.md 内コメントまたは関連 Issue 参照として記載
- Claude Code 実機で `/aidlc r` 直接開始の検証を Construction Phase で実施
- （追加達成条件 / 任意）Codex CLI 実機での同等挙動検証を Operations Phase 振り返り前段で実施

## 境界

- 委譲を廃止して親スキルに統合する案（#717 提案 2、SKILL.md 肥大化リスク回避のため不採用）
- 独立スキル化（v2.6.0+）自体の見直しは対象外（独立スキルは維持）
- `/aidlc help` / `/aidlc version` 等の委譲対象外アクションの記述変更は対象外
- Gemini CLI 検証は環境未整備のため対象外（記録のみ）

## 依存関係

### 依存する Unit

- なし

### 外部依存

- AI エージェント側の Skill ツール（Claude Code / Codex CLI 等の連鎖呼び出し挙動）

## 非機能要件（NFR）

- **パフォーマンス**: 規約変更のみで追加処理コストなし。むしろユーザー操作 1 ステップ削減
- **セキュリティ**: 影響なし（既存スキル invoke 経路の利用）
- **スケーラビリティ**: 将来委譲先スキルが増えた場合に同一規約で対応可
- **可用性**: AI エージェント側が規約に従えない場合のフォールバック（従来の案内テキスト表示）も併記

## 技術的考慮事項

- SKILL.md 記述変更のみで実装コードの変更は伴わない（AI エージェント挙動の規範として動作）
- 行番号固定参照を避け、セクション見出しアンカーで参照（保守性）
- フォールバック挙動として、Skill ツール呼び出し失敗時は従来のテキスト案内に降格する旨を明記
