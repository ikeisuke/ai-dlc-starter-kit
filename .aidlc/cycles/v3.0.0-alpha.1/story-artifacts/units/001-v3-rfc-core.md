# Unit: v3 RFC・core/extension 境界・設計判断確定

## 概要

v3 全体設計の正本となる `docs/v3/rfc.md` を作成する。7 principles、core / extension 境界、削減目標、計画書「判断が必要なポイント」6 件の trade-off 分析と結論を文書化する。後続 Unit（workflow / data-model / migration）が参照する設計判断の起点。

## 含まれるユーザーストーリー
- ストーリー 1: RFC で v3 の設計判断を確定する

## 責務
- `docs/v3/rfc.md` の作成
- AI-DLC 7 principles の記載
- core に残すもの / extension に分けるものの境界明記
- v2 → v3 削減目標（スキル / ステップ行数 / スクリプト / 設定キー）の記載
- 6 設計判断（コマンド名 / Express / v2 EOL / review 統合 / GitHub 前提 / state format）の各案 trade-off 分析 + 結論
- 分岐論点と承認結果の記録（Decision Gate Log セクション）
- v2 共存方針（変更しない前提・コマンド名衝突の扱い・consumer runtime 非影響）

## 境界
