## DR-001: 本サイクルのスコープ＝Phase 5（release）/ バージョン v3.0.0-alpha.6

- **ステップ**: セットアップ（サイクルスコープ確認）
- **日時**: 2026-06-27

### 背景

直前サイクル v3.0.0-alpha.5（Phase 4: develop normal/risky 分岐）がマージ済みで、新規 Inception の開始時にスコープとバージョンが未確定だった。Epic #736 のロードマップは次を Phase 5（release）→ v3.0.0-alpha.6 と示していたが、他にも対応候補（#733 v3 系通し振り返り、#735 v2 squash-unit backlog）が存在した。

### 選択肢

| # | 選択肢 | メリット | デメリット |
|---|--------|---------|-----------|
| 1 | Phase 5 / v3.0.0-alpha.6 | Epic #736 ロードマップに沿い、v3 単独フルサイクル（Phase 6）への前提を揃える | release フロー実装は分量が大きい |
| 2 | 別スコープを指定（#733 / #735 等） | 振り返り対応や個別 footgun 修正を優先できる | v3 リニューアルの主線が止まり、Phase 6 が遠のく |
| 3 | スコープは Phase 5 だがバージョン変更 | 特殊な版管理が必要な場合に対応 | alpha 連番（alpha.1〜5）の自然な継続から外れる |

### 決定

**選択肢 1（Phase 5 / v3.0.0-alpha.6）** を採用（ユーザー選択）。

### トレードオフと判断根拠

- **得たもの**: Epic #736 のロードマップに沿った主線の前進。release フロー実装により Phase 6（v3 単独フルサイクル）の前提が揃う。
- **犠牲にしたもの**: #733 振り返り対応・#735 footgun 修正は本サイクルでは扱わない（後続サイクル / バックログで対応）。
- **判断根拠**: Epic #736 が進捗 SoT として「Phase 5 → v3.0.0-alpha.6」を明示しており、alpha 連番の自然な継続。トレードオフスライダー（納期最小・スコープ大）に整合する主線優先の選択。
